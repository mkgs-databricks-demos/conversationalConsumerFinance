Parameterized metric views

Every consumer query passes a required consumer_guid parameter. There is no default. A query without it fails — it does not return empty, it does not fall back. The agent literally cannot construct a query that reads another customer's data.

Isolation is enforced at the SQL layer — below the agent, below the application, in the platform itself.

No other consumer AI architecture in the market provides this level of data isolation at the SQL layer.
